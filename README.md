# 📘 README - Aprendizado no Curso Spring Boot 2025 REST API's do 0 à AWS e GCP com Java e Docker

## 🚀 Introdução

Neste curso, estou aprendendo a desenvolver APIs RESTful usando **Spring Boot**, além de explorar **integrações com AWS e GCP**, e a utilização do **Docker** para facilitar o deploy das aplicações em ambientes modernos de produção.

---

## 💡 O que estou aprendendo

- **Fundamentos do Spring Boot**  
  Compreensão de como o Spring Boot simplifica a configuração e o desenvolvimento de aplicações Java.

- **APIs RESTful**  
  Aprendizado sobre os princípios de REST e como implementá-los para criar APIs robustas, escaláveis e bem estruturadas.

- **Autenticação e Autorização**  
  Configuração de segurança nas APIs utilizando tokens e controle de acesso com autenticação de usuários.

- **Integração com AWS e GCP**  
  Implantação de aplicações em nuvens públicas e utilização de serviços como **AWS S3** e **Google Firestore**.

- **Containerização com Docker**  
  Criação e gerenciamento de contêineres para facilitar o desenvolvimento, testes e entrega contínua de software.

---

## 📈 O que vou aprender

- **Testes Automatizados**  
  Criação de testes unitários e de integração para garantir a estabilidade das APIs e qualidade do código.

- **Melhores Práticas de Desenvolvimento Ágil**  
  Aplicação de metodologias ágeis, princípios SOLID e organização de código em camadas.

- **Microserviços**  
  Decomposição de uma aplicação em serviços menores, independentes e reutilizáveis, com foco em escalabilidade.

- **Monitoramento e Manutenção**  
  Uso de ferramentas para acompanhar performance, logs e saúde das aplicações em tempo real.

- **Tópicos Avançados**  
  Exploração de segurança, versionamento de APIs, documentação com Swagger/OpenAPI, e práticas modernas de DevOps.

---

## 🧠 Nível do curso

Este curso é indicado para desenvolvedores com conhecimentos básicos em Java que desejam expandir suas habilidades em:

- Desenvolvimento de APIs modernas com Spring Boot
- Acesso a bancos de dados com JPA/Hibernate
- Segurança com JWT e autenticação
- Deploy em nuvem (AWS/GCP)
- Docker e práticas DevOps
